# Task 2: Personal Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript for a web development internship assignment.

## Run locally

Download or clone the repository, then open `index.html` in a modern browser. No installation, build command, or API key is needed.

## Features

- Hero, About, Projects, and Contact sections.
- Responsive navigation and layouts for desktop and mobile.
- Button hover transitions, scroll reveals, and reduced-motion support.
- Three working sample projects: a studio landing page, a task manager, and a calculator.
- Browser-local task storage and keyboard calculator controls.

## Personalization

The portfolio is personalized for Sarthak Gandhamwar. The biography and project descriptions remain sample content and can be edited in `index.html`. Keep descriptions accurate when replacing the sample projects with your own work.

Contact links open the visitor's email application. There is no backend contact form or server-side message delivery. Task-manager data stays in the current browser when local storage is available.

## GitHub Pages

Check **Settings > Pages** for the current deployment status and published URL. To deploy this static site, select **Deploy from a branch**, branch **main**, and folder **/(root)**. Keep `index.html`, `styles.css`, `script.js`, `assets/`, and `projects/` at the repository root.
